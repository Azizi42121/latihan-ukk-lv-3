# Panduan Penggunaan Aplikasi (User Guide) - Etalase Digital Stella

Dokumentasi ini merinci alur penggunaan fitur dan hak akses (*role-based authorization*) di dalam aplikasi **Etalase Digital Stella**.

---

## 1. Fitur Umum (Publik / Semua Pengguna)
* **Pencarian Karya (Search Bar):** 
  * Kotak pencarian (`Katalog Karya Siswa`) dapat diakses dan digunakan oleh siapa saja (baik pengunjung umum, siswa, admin, maupun super admin) untuk mencari judul project atau karya dengan cepat menggunakan tombol **Cari**.

---

## 2. Hak Akses Siswa (`siswa`)
Siswa berperan sebagai kontributor utama yang dapat mengunggah dan mengelola karya pribadi mereka.
* **Tambah Karya:** Menggunakan tombol **+ Tambah Karya** di bilah navigasi atas untuk mempublikasikan portofolio project baru.
* **Kelola Karya Sendiri:** Siswa memiliki hak akses tombol **Edit** dan **Hapus** *hanya* pada kartu project / karya yang mereka unggah sendiri. Mereka tidak dapat mengubah atau menghapus karya milik siswa lain.

---

## 3. Hak Akses Admin (`admin`)
Admin bertugas mengawasi dan memoderasi seluruh konten yang ada di dalam platform.
* **Tambah Karya:** Dapat mengunggah karya baru melalui tombol **+ Tambah Karya**.
* **Kelola Semua Karya:** Admin memiliki akses penuh berupa tombol **Edit** dan **Hapus** pada **seluruh** kartu karya / project yang terdaftar di platform, tanpa batasan kepemilikan.

---

## 4. Hak Akses Super Admin (`super_admin`)
Super Admin adalah tingkat tertinggi dalam sistem dengan hak istimewa penuh atas konten dan manajemen pengguna.
* **Manajemen Pengguna (Kelola Users):** Memiliki tombol khusus **Kelola Users** di bilah navigasi atas untuk mengatur akun-akun yang terdaftar di dalam sistem.
* **Kelola Semua Karya:** Memiliki hak akses penuh untuk melakukan **Edit** dan **Hapus** pada semua project/karya yang ada di katalog.
* **Tambah Karya:** Dapat mengunggah project baru melalui tombol **+ Tambah Karya**.
